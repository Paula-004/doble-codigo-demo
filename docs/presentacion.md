## Texto para portfolio

**Doble Código · Landing responsive para un estudio ficticio de software**

Diseñé y desarrollé Doble Código para mostrar cómo presentaría los servicios, el proceso de trabajo y los proyectos de un estudio de software en una sola página. Trabajé con React, Vite y CSS y definí una identidad visual oscura con acentos violetas, un logotipo y una gráfica orbital en la portada.

Creé tres casos ficticios de portfolio: una vidriera web, una agenda móvil y un panel de inventario. Cada tarjeta explica el desafío y la solución propuesta, e incluye una vista ilustrada en HTML y CSS. También implementé una consulta simulada que genera un borrador en el navegador con opciones de ejemplo, sin pedir datos personales, realizar envíos ni guardar información.

Probé el sitio en siete anchos de pantalla y verifiqué que se pueda recorrer con el teclado. Incorporé foco visible, un enlace para saltar al contenido, cierre con Escape y restauración del foco en la consulta. Automaticé los recorridos principales con Playwright y actualicé las dependencias afectadas por avisos de seguridad. En una medición local con perfil móvil simulado, la mediana de LCP de la versión de producción fue de 1,44 s.
